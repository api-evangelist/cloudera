# Cloudera Documentation

> Product documentation for Cloudera's data platform, including CDP, Cloudera Manager, Data Services, and related tools.

## Getting started

Recommended starting points for new users, covering the main deployment models for Cloudera's data platform. Curated by the docs team; entries here surface in the site-root llms.txt for AI discoverability.

- [Get started with CDP Public Cloud](https://docs.cloudera.com/cdp-public-cloud/cloud/index.html): Register environments, provision workload clusters, and deploy Data Hub, Data Warehouse, Machine Learning, Data Engineering, and Operational Database on AWS, Azure, or GCP.
- [Get started with CDP Private Cloud](https://docs.cloudera.com/cdp-private-cloud/latest/index.html): Install and manage the Cloudera Data Platform on-premises. Umbrella entry covering both Private Cloud Base (Cloudera Manager + Runtime) and Data Services.
- [Get started with Cloudera Data Services on premises](https://docs.cloudera.com/cdp-private-cloud-data-services/latest/index.html): Deploy Cloudera Data Warehouse, Data Engineering, Machine Learning, and Operational Database as Kubernetes services on an existing Private Cloud Base cluster or Embedded Container Service.
- [Get started with Cloudera Manager](https://docs.cloudera.com/cloudera-manager/latest/index.html): Centralized management software for installing, configuring, and monitoring clusters running Cloudera services on-premises or in the cloud.
